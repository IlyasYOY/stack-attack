# Stack Attack

Рабочее название собственного 2D-аркадного проекта для Android и Web на Godot 4 + GDScript.

## Состояние

Базовый приватный репозиторий подготовлен для подключения облачного окружения. Игровой код и сборки ещё не реализованы. Версия Godot будет закреплена при настройке окружения.

## Документы

- [Согласованный план и правила](docs/plan.md)
- [Подготовка облачного окружения](docs/cloud-environment.md)

Первая техническая часть: минимальный Godot-проект, простой тест и проверка Android/Web-экспорта. Реализация начнётся после создания облачного окружения Ильёй.

Создаём собственные графику, звук и название. Stack Attack, Braid и Dead Cells используются только как референсы механик и визуального направления; их материалы не копируются.
