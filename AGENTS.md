# Работа над проектом

- Сначала читать README.md и docs/plan.md. Отличать принятые решения от предложений и открытых вопросов.
- Android и Web — обе целевые платформы. Не исключать одну ради другой.
- Изменения делать небольшими проверяемыми частями; PR по умолчанию draft.
- Не добавлять новые механики и не менять согласованные правила под видом технической настройки.
- Не объявлять проверки пройденными, если они не запускались; указывать ограничения окружения.
- Не хранить ключи, пароли, токены, keystore и экспортные credentials в репозитории.
- Не запускать задачи на компьютере Ильи без явного разрешения использовать этот компьютер.
- До подготовки облачного окружения это документационная основа, не разрешение начать реализацию игры.
