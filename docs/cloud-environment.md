# Облачное окружение

## После создания репозитория

Илья создаёт Codex cloud environment, подключённое к этому приватному репозиторию. Настройка должна обеспечивать доступ к checkout и возможность запускать команды сборки. Секреты подписи на этом этапе не нужны.

## Первая техническая часть (ещё не выполнена)

1. Выбрать стабильную версию Godot 4 и закрепить её вместе с соответствующими export templates. Не использовать плавающее latest.
2. Подготовить GDScript-проект и минимальную запускаемую сцену без игровых механик.
3. Настроить инструменты Android по официальной инструкции выбранной версии Godot (JDK и Android SDK, необходимые build tools).
4. Проверить headless-импорт, простой автоматический тест и экспорт Android APK и Web.
5. Отдельно проверить графический запуск/браузер в окружении; headless-проверка не доказывает корректность изображения.
6. Описать точные воспроизводимые команды в README после проверки. Пока проверенных команд сборки нет.

Compatibility — исходная рекомендация для проверки, не гарантия всех желаемых эффектов. Место публикации Web-сборки ещё не выбрано. Публичный hosting, релизы и подпись не включаются автоматически.

## Проверка первой части

- Зафиксированы версии инструментов.
- Один и тот же commit экспортируется для двух платформ.
- APK запускается на телефоне, Web-сборка открывается в браузере.
- Автоматический тест действительно выполнен, ограничения записаны.
