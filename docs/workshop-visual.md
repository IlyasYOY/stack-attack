## Что реализовано

- Собственные ящики 48×48: диагональная деревянная доска, бирюзовые X-раскосы, металлический вентилируемый вариант. Их цвета и внешний вид не создают новых свойств.
- Механик 32×48: кепка с очками, большой читаемый силуэт головы, рубаха, шарф, ремень, ботинки и красный магнит с металлическими наконечниками. Стойка, шаг, прыжок, толкание; каждый кадр также существует без магнита.
- Рама поля, болты, тёплый рельс и краны, лампа с дешёвым прозрачным световым конусом; фабричные балки, окна, шестерни и верстак. Нет нового физического света, 3D или дорогого постпроцессинга; Compatibility/WebGL 2 сохранён.
- Собственный bitmap-шрифт small caps с кириллицей/латиницей, общие компактные кнопки с небольшими креплениями и металлической границей, кремовые пиктограммы управления, аккуратная табличка счёта. Меню сохраняют название и прежние пункты, без подзаголовков/футеров/прокрутки. Живой AI-фон сохранён.

Ассеты воспроизводятся `python3 scripts/generate_art.py` и `python3 scripts/generate_font.py` с Pillow. Они нарисованы примитивами/матрицами проекта, не вырезаны из референса и не заимствованы из других игр. SVG-иконка также собственная.

## Граница механики

`simulation.gd`, `tuning.gd`, `prototype.tres`, `demo.gd`, `profile.gd`, `sound.gd` не меняются. Поле 10×11, коллизии, скорости, сбросы, очистки, поражения, очки, управление и сохранение прежние. Размеры и позиции touch-областей прежние. Новый счёт подгоняет шрифт внутри таблички, без изменения значения.

Магнит — только текстура в `StackWorldView`, не способность. Нет слотов, зарядов, открытия/покупки, выпадения, притяжения и новой кнопки. В обычной сборке герой показан с ним как художественный кандидат. Явный debug Web fixture `hero_pose` допускает `magnet: false` для сравнения вариантов; он не доступен через обычный UI. Стойка и направление определяются чтением текущего состояния, без изменения симуляции.

Полный sprite canvas не обрезается при отражении. При выводе 16×24 и offset (-1,-2) ось туловища остаётся на прежнем x=7 относительно player, маленький выступ кепки и рук косметический. Картинка не меняет коллизию. Проверяется реальный цветовой ориентир на шарфе, а не центр alpha-силуэта, который естественно меняется из-за инструмента.

## Проверка и показ

```bash
source /workspace/setup-stack/env.sh
bash scripts/check.sh
source /workspace/stack-attack-local/debug-signing/debug-signing.env
bash scripts/export.sh all
python3 scripts/check_web.py
python3 scripts/package_builds.py
python3 scripts/package_showcase.py
```

Полный Web-набор включает `--workshop-only` и `--sprites-only`: портрет/альбом/Fold, реальный цвет магнита в игровом масштабе, позы с/без инструмента, обе стороны при одной позиции, центр туловища, alpha-поля, покрытие шрифта, меню и обычную партию. Поза толкания берётся из близости к реальному ящику; в игре это только анимация.

Для Library заранее выбран **один** небольшой PNG-лист из нескольких реальных кадров (один файл, fast path до 50 MiB), а не batch отдельных картинок через ранее недоступный upload helper. Исходные PNG сохраняются отдельно в `build/screenshots/`. Лист содержит подписи вне игрового UI и целочисленно увеличенный фрагмент реального кадра. Ничего не публикуется публично. Успех сохранения и Library ID сообщаются только после подтверждения инструмента.

APK и Web доставляются приватным Actions artifact. CI использует временную debug-подпись каждого run; при установке вместо предыдущего теста может понадобиться удаление старого APK с его данными. Физический Android, сила вибрации, вырезы экрана и производительность на телефоне агентом не проверяются. Fold в браузере — размер viewport. Оценка выразительности, масштаба героя и деталей остаётся за Ильёй.
